# 분석 퀄리티 지침 (living document)

이 문서는 추천/분석 알고리즘의 **품질 기준**과, 제안된 아이디어가 검증을 통과했는지를
기록하는 **신호 원장(signal ledger)**이다. 지속적으로 갱신한다.

## 방법론 — 아이디어는 구현 지시가 아니라 검증할 가설

1. 주어진 아이디어/직관은 **하나의 가설**로 둔다. 그대로 구현하지 않는다.
2. 그 아이디어에서 인사이트·맥락을 추출해 **관련 학술 이론·설계 원칙·프레임**에 비춰
   통계적·심리학적·분석적으로 검증한다.
3. **살아남은 신호만** 아래 원장에 `SURVIVED`로 올리고 제품에 반영한다. 식별 불가능하거나
   교란·순환·과대주장인 것은 `REJECTED`로 남겨 재발을 막는다.
4. 모든 신호는 **불확실성(confidence)** 을 달고 전파한다. 근거가 얇으면 단정하지 않는다.
5. 반례·신규 근거가 생기면 원장을 갱신한다(자기 정정 포함).

## 검증된 핵심 원칙 (constitution)

| # | 원칙 | 근거 |
| --- | --- | --- |
| P1 | **드러난 선호 > 명시적 선호.** 플레이타임이 1차 증거, 소유·태그·카테고리는 약하고 불확실한 2차 신호. | 현시선호 이론(Samuelson); stated preference의 체계적 과대평가(hypothetical bias) |
| P2 | **결측 ≠ 평균.** 미상 데이터가 평균·양호로 점수화되면 안 된다. 품질-미상 = 보수적 최저(WLB 0), 적합도-미상 = 중립(분포 제외, 상향 금지). | 소표본 과대평가 방지; 측정 정직성 |
| P3 | **confidence 전파.** 모든 파생 신호는 표본/커버리지 기반 confidence를 갖고, 낮으면 단정 대신 감쇠. | 측정 신뢰도; 이슈 #2 §1 |
| P4 | **모수 대비 정규화.** 관심/친화도는 원시 빈도가 아니라 **모집단 기저율 대비(lift)** 로. | 인기도·기저율 교란 제거 |
| P5 | **식별 가능한 것만 추론.** 데이터로 식별 불가능한 것(예: 번들 여부—구매정보 없음)에 분류기를 만들지 않는다. 모드 추론은 명확한 게임에서만. | 식별 가능성; 필터버블 위험 |
| P6 | **행동 요약이지 심리 진단이 아니다.** 플레이 패턴 축은 정의된 행동 지표이며, 검증된 동기/성격 구인이 아니다(그건 자기보고 요인분석 기반). 정의+confidence와 함께 정직하게 표기. | Quantic Foundry 동기 모델은 설문 기반; 행동 프록시의 구인타당도 미검증 |
| P7 | **안정 스케일링.** 후보 집합에 따라 흔들리는 in-pool z 대신 고정 범위/캐시된 percentile. | 후보 추가·삭제에 점수 불변(재현성) |
| P8 | **비게임 제외.** Software/Utilities/DLC/데모/사운드트랙은 취향·persona·클러스터에서 제외. | 프로필 오염 방지 |

## 채택/폐기 기준 (adoption / rejection)

- **채택 N = 2.** 승격(PROMOTED)은 **독립 렌즈 근거 ≥2개** AND **반증 탐색에서 미반박**을 동시에 만족할 때만.
- **조건부(PENDING).** 반증에서 *특정 조건 하에서만* 생존한 후보. 조건(식별가능 부분집합·기저율 lift·coverage 등)이 구현·확인되면 승격 심사.
- **폐기 기준(하나라도 저촉 시 REJECTED)**
  - R1 **식별 불가능** — 참/거짓을 가를 관측 조건을 현재 데이터로 만들 수 없다.
  - R2 **순환·교란** — 결론을 입력으로 쓰거나 교란변수와 분리 불가.
  - R3 **원칙 위반** — P1–P8 중 하나에 저촉.
  - R4 **반증 우세** — 선언된 렌즈에서 반박 근거가 지지 근거를 압도.
  - R5 **과대주장** — 데이터가 뒷받침 못하는 구인/인과를 단정.
- **재심 금지.** 판정된 신호는 *새 반증*이 없으면 재심하지 않는다(수렴).

**수렴 검증(이번 패스):** 승격 9건 전부 N≥2 또는 정의적, 반증 미반박. 조건부 4건은 조건 미충족으로 미승격(정상). 폐기 1건. 원장 내 중복·모순 없음. 미반영 승격(C4·C5·C10·C12, 부분 C6·C11)이 남아 **배치는 소진됐으나 상태 변경 있음 → 다음 패스 계속**(구현·검증으로 상태 닫기).

## 검증 상태(오프라인/실계정)

- 단위/속성 테스트로 각 원칙을 강제(P2·P4·P7·P8 등)한다.
- 실계정 smoke: 비게임 클러스터 소멸, 0% 클러스터 미표시, 결측 신작 일괄 고fit 미발생 확인.
- 정확도만 오르고 다양성/calibration이 악화되면 성공으로 보지 않는다(이슈 #2 평가지표 준용).
